// 01 · Features

一个框架，全部可扩展

不再被写死的组件束缚。每个核心能力都通过 Expand API 开放，扩展即代码。

/01

四层架构

Core / Expand API / Extension / Runtime 四层清晰分离，依赖单向，职责明确。

/02

模型无关

不绑定任何 AI 模型 SDK，think 只依赖可插拔的推理后端抽象，自由替换。

/03

统一 Expand API

@expand_hook 装饰器 + register_extension，九个扩展点覆盖完整生命周期。

/04

安全隔离

扩展加载与执行异常被隔离，单扩展失败不影响框架与其他扩展，越权访问被拦截。

/05

三种调度策略

串行、并行、优先级队列开箱即用，也可实现自定义调度器无缝接入。

/06

内置运行时

9635 端口提供 REST API，webrun 命令动态开启浅/深色 Web 控制台。

// 02 · Architecture

四层架构

从核心逻辑到运行时加载，每一层都可被扩展替换。

Extension Layer 扩展实现
开发者编写的自定义扩展：工具、记忆后端、调度策略。
weathersqlite_memoryround_robin
Expand API Layer 扩展接口
统一的扩展入口：@expand_hook、register_extension、ExtensionHandle。
ExpandHookExtensionLoader
Core Layer 核心逻辑
Agent 循环、工具注册表、记忆、调度器、推理后端。
ThinkStackAgentToolMemoryScheduler
Runtime Layer 运行时加载
HTTP REST API 与 Web 控制台，负责对外通信与扩展加载。
ThinkStackServerWebConsole

// 04 · Quick Start

快速开始

一条命令启动，任何人都能接入 9635 端口构建 Agent 应用。

启动框架
python run.py
# ThinkStack REST API
#   http://0.0.0.0:9635
调用 REST API
curl -X POST .../api/agent/run \
 -d '{"agent":"echo","input":"你好"}'
curl -X POST .../api/command \
 -d '{"command":"webrun 8080"}'
用代码接入
from thinkstack import ThinkStack, EchoAgent
stack = ThinkStack()
stack.start()
stack.run_agent(EchoAgent(), "你好")
编写扩展
@expand_hook(ExpandHook.HOOK_CUSTOM_TOOL)
def register_tool():
    return FunctionTool(
      name="weather", ...)

开始构建你的 Agent 应用

ThinkStack 开源、模型无关、可扩展。运行即接入。
